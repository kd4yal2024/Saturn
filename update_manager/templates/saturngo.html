Rebuild & Redeploy Saturn Go (Terminal)

Runs update-saturn-go.sh with live terminal output. It uses the Saturn Go policy (right panel), rebuilds the Rust backend, updates templates, and dispatches a detached self-redeploy.

Use Skip Git for local rebuild/redeploy tests. Use Dry run to preview all steps without changing the system.
Note: the terminal connection may drop near the end when saturn-go.service restarts. Reload the page after 10-20 seconds.
