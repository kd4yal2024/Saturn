Settings Backup

Downloads a small, versioned archive of Saturn Remote settings and profiles, registered operator scripts, and piHPSDR/deskHPSDR property files. It excludes passwords, remembered-device and TLS secrets, Tailscale/Wi-Fi identity, host identity, boot configuration, logs, repositories, releases, and FPGA contents.

Treat this as private operator data: radio property files and custom scripts may contain sensitive values. Settings restore validates the manifest and checksums, retains rollback data, and recovers an interrupted transaction at startup.

Settings Restore

Host-specific policy is skipped by default so an imported backup cannot silently change this appliance's repository or update source.

Transactional Source Restore

This accepts a Saturn source archive, creates and flushes a new repository generation, then atomically switches the active repository pointer. The previous checkout is retained. It does not import settings or activate an installed immutable release. Use Validate first.

Legacy Script Source Backups

These are source-tree rollback copies created by update-G2.py (saturn-backup-*) and update-pihpsdr.py (pihpsdr-backup-*), not appliance backups.

Repair Pack

Downloads a tar.gz with the critical runtime, config, and service files needed to repair a broken system.
