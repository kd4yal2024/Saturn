Saturn Bridge TCI Server

The TCI server broadcasts receive frequency (vfo:), authoritative transmit frequency (tx_frequency:), and TX state (trx:) to every connected client, the same way Saturn Remote's browser connection works. Point a TCI-compatible accessory (e.g. an amplifier that follows band/frequency changes) at this address to have it track the radio automatically.

LAN clients are read-only accessories. A client that connects through a non-loopback address can receive frequency, mode, meters, and TX state, but it cannot become operator or key TX. Loopback connections through Saturn Go remain the control path.
