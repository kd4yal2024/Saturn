Operational notes and recovery
- Default service is p2app.service.
- Service restarts now flow through saturn-xdma-ready.service, so XDMA/PCIe readiness is checked before the radio app starts.
- The readiness gate is a one-shot service; after a successful run it normally shows inactive (dead) with a successful result.
- Deploy installs the converged binary under /opt/saturn-go/p23-apps/ and refreshes the current symlink.
- Service restarts and panel-mode changes use a systemd drop-in override (safer than editing the main unit file).
- If a restart fails because the XDMA stack is not ready, the terminal log will include output from saturn-xdma-doctor.sh.
- Front panel mode sets SATURN_FRONT_PANEL_MODE for p2app: use g2 or g2v2 if auto-detect picks the wrong panel.
- Performance view combines host metrics with app-published counters from /dev/shm when available.
- ADC peak telemetry is optional and writes only a latest-snapshot JSON file in /dev/shm while enabled.
- Web mode requires working sudo -n permissions for install/restart steps.
- Shell restore: sudo /opt/saturn-go/scripts/p23-app-manager.sh --revert --verbose
