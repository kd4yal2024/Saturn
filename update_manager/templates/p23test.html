Notes

- Default service is p2app.service.
- Deploy installs binaries under /opt/saturn-go/p23-apps/ and switches a current symlink.
- Service switching uses a systemd drop-in override (safer than editing the main unit file).
- Front panel mode sets SATURN_FRONT_PANEL_MODE for P2/P3: use g2 or g2v2 if auto-detect picks the wrong panel.
- Performance view combines host metrics with app-published counters from /dev/shm when available.
- ADC peak telemetry is optional and writes only a latest-snapshot JSON file in /dev/shm while enabled.
- Web mode requires working sudo -n permissions for install/restart steps.
- Shell emergency revert: sudo /opt/saturn-go/scripts/p23-app-manager.sh --revert --verbose
