Saturn Remote

Direct G2 control with a browser-native display path.

This page is the first independent saturn-remote frontend: DOM for control and session state, WebGL2 for high-DPI spectrum and waterfall, and saturn-bridge as the protocol boundary underneath.

Control Plane
DOM + TCI
Connection status, VFO, mode, filters, sample rate, and session diagnostics stay in the normal document layer.
Display Engine
WebGL2
Spectrum and waterfall render into dedicated GPU canvases, sized against devicePixelRatio for crisp shack displays.
LAN Contract
Raw IQ Now
The current bridge sends TCI-style float32 IQ frames directly. This keeps the first browser path honest and close to the radio.
WAN Direction
FFT Rows Later
For internet use, move panadapter transport toward display-oriented FFT rows and compressed audio instead of raw IQ everywhere.
