1. Install

Installs the Tailscale package via the official installer (https://tailscale.com/install.sh) and enables tailscaled.service. Skip this step if Tailscale is already installed.

2. Bring Up / Authenticate

Run tailscale up. With no auth key, Tailscale will print a one-time login URL in the output below — open it in a browser to add this Pi to your tailnet. With an auth key (recommended for headless setups), it joins automatically.

Leave blank to keep the existing tailnet hostname. Pick a unique name — generic names like raspberrypi collide on tailnets with multiple Pis.

3. Disconnect

Down drops this node from the tailnet but keeps the saved auth, so a later up reconnects without re-login. Logout forgets the node key — the next up will require browser login or a new auth key.

4. Tailscale Serve (Saturn Remote)

Exposes the Saturn Remote TLS listener (127.0.0.1:8443/remote-next) over your tailnet. Serve On runs saturn-go-tailscale-serve.sh, which refuses to configure unless every Saturn safety gate passes (auth, hostname, listener reachability). See docs/OPERATIONS_RUNBOOK.md → Secure Remote Access with Tailscale.
