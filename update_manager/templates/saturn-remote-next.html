Operator Controls

          
Keyboard, mouse, and touch controls currently wired on this page.

        

        
      

      

        

          
Frequency

          
0-9Open direct frequency entry from the operating canvas.

          
EnterApply the direct-entry value using the inferred unit.

          
EscClose direct entry. If TX is active, emergency unkey still runs.

          
Tap digitSelect the VFO tune step shown by the underline.

          
Wheel digitTune the selected digit up or down.

          
Up / DownTune the active VFO step from the operating canvas.

          
Shift + Up/DownTune 10x the active VFO step.

          
Ctrl + Up/DownTune 100x the active VFO step.

          
Alt + Up/DownTune one tenth of the active VFO step, down to 1 Hz.

        

        

          
Panadapter

          
Tap / dragQSY the RX frequency across the visible spectrum.

          
WheelTune in 100 Hz steps while the pointer is over spectrum or waterfall.

          
Shift + wheelTune in 1 kHz steps.

          
Ctrl + wheelZoom the displayed span.

          
Drag edgeAdjust RX filter low or high cut.

          
Drag passbandShift the RX passband within the current filter limits.

        

        

          
TX Safety

          
Hold PTTMouse or touch hold-to-key; release unkeys. If TX is locked, first press only arms.

          
MOXToggle transmit from the separate MOX control after TX is armed.

          
BacktickKeyboard MOX toggle from the operating canvas, with the same TX-ready gate.

          
Hold SpaceHold-to-key from the operating canvas. If TX is locked, the first press only arms.

          
Lock TXDrop any ready or keyed state back to TX locked without leaving the TX zone.

          
EscEmergency unkey from anywhere on the page.

          
Window blurKeyboard PTT unkeys and requires reconfirm if the browser loses focus.

          
Page hideLeaving or hiding the page forces an unkey and TX reconfirm.

        

        

          
Display

          
WFToggle the phone waterfall without leaving the panadapter.

          
Freq LockPrevent QSY from digit, keypad, and panadapter controls.

          
?Open or close this operator control sheet.
