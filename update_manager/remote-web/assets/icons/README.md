# Saturn Remote icon sprite

The symbols in `sprite.svg` are compact copies of the official Lucide outline
SVGs at commit `66d8f9fc394b8530377e5f6112f0b8908ba01280`:

<https://github.com/lucide-icons/lucide/tree/66d8f9fc394b8530377e5f6112f0b8908ba01280/icons>

Symbols: `radio`, `settings-2`, `power`, `volume-2`, `wifi`,
`triangle-alert`, `check`, `chevron-down`, `x`, `menu`,
`sliders-horizontal`, and `headphones`. The licenses are in
[LICENSE.txt](LICENSE.txt) and embedded in the delivered single-file bundle's
asset notices.
