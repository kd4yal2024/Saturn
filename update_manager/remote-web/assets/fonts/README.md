# IBM Plex webfont subset

The four WOFF2 files are the official IBM Plex Sans and Mono Latin-1 subsets,
normal weights 400 and 500, copied from IBM's `plex` repository at commit
`763c36ef9117782905ae010056dfbe8fd2653a25`:

<https://github.com/IBM/plex/tree/763c36ef9117782905ae010056dfbe8fd2653a25/IBM-Plex-Sans/fonts/complete/woff2>

<https://github.com/IBM/plex/tree/763c36ef9117782905ae010056dfbe8fd2653a25/IBM-Plex-Mono/fonts/complete/woff2>

The full SIL Open Font License 1.1 is in [OFL.txt](OFL.txt) and is embedded in
the delivered single-file bundle's asset notices.
